# Agent Skills examples

Open a `SKILL.md` and its preview (**Markdown Studio: Preview: Open Beside**).

- [sample-skill/SKILL.md](sample-skill/SKILL.md) — valid. The preview shows a card with the name, description, tools and metadata. No warnings.
- [BadName/SKILL.md](BadName/SKILL.md) — intentionally invalid. The Problems panel lists Agent Skills warnings: name format, folder mismatch, missing description, non-string metadata, and a missing referenced file.

Rules follow the [Agent Skills specification](https://agentskills.io/specification).
