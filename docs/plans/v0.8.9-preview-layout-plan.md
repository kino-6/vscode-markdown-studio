# v0.8.9 Preview Layout Plan

## Goal

Add small Preview ergonomics before v0.9:

- Open Preview in the current editor group when requested.
- Open Preview without the normal content width limit when requested.
- Make Preview content width configurable, defaulting to A4-like width.
